# Changelog

All notable changes to Playdub will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project
uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Initial Tauri, React, and Rust application shell.
- GitHub Actions for validation and cross-platform desktop builds.
- Open-source governance, AI development, architecture, and model licensing policies.
- Prototype local video playback with standard transport controls.
- Local media selection and WebView-safe asset loading through the trusted Rust core.
- User-configurable FFmpeg audio extraction and whisper.cpp transcription pipeline.
- Whisper English translation path and optional llama.cpp/GGUF text-translation path.
- Bilingual, time-aligned subtitle rendering with generation-aware task cancellation.
- Prototype setup, limitations, smoke-test, and external-tool licensing documentation.
